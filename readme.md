## 1. Windows 빠른 지원 vs 디스코드

| 비교 항목     | Windows 빠른 지원              | 디스코드               |
| --------- | -------------------------- | ------------------ |
| 설치        | Windows 11에 기본 제공되는 경우가 많음 | 별도 설치 또는 웹 접속      |
| 회원가입      | 도움받는 사람은 별도 계정 불필요         | 양쪽 모두 계정 필요        |
| 연결 방법     | 6자리 보안 코드 입력               | 친구 추가 후 통화         |
| 화면 보기     | &#x20;가능                   | &#x20;가능           |
| 원격 마우스 조작 | &#x20;가능                   | &#x20;불가능          |
| 원격 키보드 조작 | &#x20;가능                   | &#x20;불가능          |
| 음성 대화     | 별도 전화 등이 편리                | 음성통화 내장            |
| 초보자 문제 해결 | 매우 적합                      | 설명을 듣고 직접 조작할 때 적합 |

## 3. Windows 빠른 지원 사용법 — 아주 간단합니다

내 컴퓨터 (도움을 주는 사람)

1. 키보드에서 `Ctrl + Windows + Q`를 누릅니다.
2. 다른 사람 지원(도움 주기) 을 클릭하고 Microsoft 계정으로 로그인합니다.
3. 표시되는 6자리 보안 코드를 친구에게 알려줍니다.

   친구 컴퓨터 (도움을 받는 사람)
4. `Ctrl + Windows + Q`를 누릅니다.
5. 전달받은 6자리 코드를 입력하고 제출합니다.
6. 허용 버튼을 클릭합니다.

   원격으로 문제 해결

   내 화면에 친구 컴퓨터 화면이 나타나면 제어 요청을 클릭합니다. 친구가 이를 승인하면 직접 마우스와 키보드를 조작할 수 있습니다.&#x20;

   [image](https://www.google.com/s2/favicons?domain=https://learn.microsoft.com\&sz=32)

   Microsoft Learn



주의할 점은 빠른 지원을 실행할 때 앱 설치가 필요할 수도 있으며, 원격 제어는 반드시 친구의 허가를 받아야 한다는 것입니다. 연결 종료 후에는 제어 권한도 종료됩니다.

결론: 평소 디스코드를 사용하던 친구라면 화면 공유가 편할 수 있지만, 컴퓨터 사용에 익숙하지 않은 친구의 문제를 원격으로 직접 해결하려면 Windows 빠른 지원이 더 적합합니다.

특히 Windows 설정 변경, 프로그램 설치 문제, 프린터나 네트워크 오류를 해결해 줄 때 유용합니다.
